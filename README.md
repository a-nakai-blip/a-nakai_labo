# Nakai Laboratory Website (English)

This repository contains the static website for Nakai Laboratory, Osaka Electro-Communication University.

## Publish with GitHub Pages

1. Create a GitHub repository named `nakai-laboratory`.
2. Upload the contents of this folder to the repository root (do not upload the enclosing folder itself).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for the deployment. The site URL will normally be `https://YOUR-USERNAME.github.io/nakai-laboratory/`.

The homepage is `index.html`.

## Files

- `index.html` — laboratory homepage
- `publications.html` — books, academic papers, and conference presentations
- `basketball.html` — men's basketball club page
- `style.css` — shared styles
- `.nojekyll` — disables Jekyll processing for static assets

## Editorial checks before public release

- The university database currently lists 2 book/book-chapter records, 52 academic-paper records, and 109 conference-presentation records.
- All 52 academic-paper titles and both book titles are translated in `publications.html`.
- The 15 most recent conference presentations are translated in this edition; the complete list of 109 is linked to the official Japanese faculty database.
- DOI links are included where DOI information is available. Add PDF links only after checking open-access status and copyright permissions.
- Confirm consent and university policy before publicly displaying student names, research topics, or photographs.
- Verify official club name, schedule, venue, league affiliation, and results before adding specific details.
- English translations of Japanese titles and grant names should be reviewed by the researcher before final publication.
